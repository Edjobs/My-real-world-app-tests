# My real world app test

This is a project that utilizes cypress to create tests for the "Real world app" (https://github.com/cypress-io/cypress-realworld-app), in which you need to install that one before. 

It tests the app's login, transactions and seeing the transactions history's functions.

## Requirements

Need to install the real world app and then copy my (this git's) cypress files into them.

## Location

Its on Cypress -> Tests -> E2E
